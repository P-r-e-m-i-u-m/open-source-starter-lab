## Merging: Why We Use Squash Merge

When your PR is ready, we'll use the **"Squash and merge"** button.

**What this means for you:**
- Your individual commits get combined into one commit
- The commit message becomes the PR title and description
- Your messy commit history disappears from `main`

**You don't need to worry about:**
- How many commits you made
- How clean your commit messages are
- Force-pushing or fixing typos

We only care about the final PR. For a detailed explanation, see [Merge Strategy](docs/MERGE_STRATEGY.md).
